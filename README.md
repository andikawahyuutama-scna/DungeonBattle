# DungeonBattle

Dungeon Battle

A simple turn-based dungeon battle game built with C# and .NET Console. The player must fight multiple monsters, manage HP and potions, and defeat all enemies to achieve victory.

🎮 Features
⚔️ Turn-based battle system
👤 Custom player name
👹 Multiple monsters
❤️ HP and health management
🧪 Healing potion system
🔥 Critical hit system
💰 Gold rewards
🏆 Victory and Game Over system
🎲 Randomized critical hit chance
📊 Player status display
🛠️ Technologies
C#
.NET
Console Application
